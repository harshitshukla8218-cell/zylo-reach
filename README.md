# Zylo Reach - Cold Email Automation Engine

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/harshitshukla8218-cell/zylo-reach)

Cold email outreach automation web application built for Zylo Digital.

## Features
- **Frontend Dashboard:** Enter Sender Name, Company, Gmail, and Google App Password directly in the UI.
- **CSV & Excel Upload:** Drag and drop `.csv`, `.xlsx`, or `.xls` lead sheets.
- **Smart Lead Filtering:** Automatically filters out unverified/missing emails to keep domain bounce rate at 0%.
- **Niche-Specific Personalization:**
  - Cafes: Local SEO, Google Maps, AI food reels, online menus.
  - Fashion & Boutiques: E-commerce UX, Meta catalog ads, AI product videos.
- **🧪 Safe Simulation Mode:** Test runs without sending real emails.
- **⚡ Live Sending Mode:** Sends real emails with human-like delays (40-70s).
- **CAN-SPAM Compliant:** Built-in unsubscribe opt-out and clean professional footers.
